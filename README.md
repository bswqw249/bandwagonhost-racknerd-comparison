## 什么是搬瓦工（BandwagonHost）？一句话先搞清楚

搬瓦工（BandwagonHost，简称 BWG）是加拿大 IT7 Networks 旗下的 VPS 品牌，成立于 2004 年。它在国内用户圈最出名的一点，是提供**CN2 GIA 等中国大陆高速优化线路**，还有自研的 KiwiVM 控制面板，支持在十几个机房之间自助一键切换，完全不需要提工单。

简单说：搬瓦工是国内用户玩得最久、口碑积累最扎实的中高端 VPS 商家之一，主打"买一次，网速舒心用"的体验。

RackNerd 成立于 2019 年，主营美国 KVM VPS，洛杉矶、圣何塞、纽约、西雅图等机房都有，数据中心依托 ColosCrossing 等基础设施。它走的是另一条路：配置给足，价格压到极致。根据各 VPS 社区的实测反馈，RackNerd 年付最低能到 10 美元出头，在"便宜 VPS"这个细分里性价比极高。

## 线路质量：差距就在这里

这是两家最核心的区别，很多人买便宜货踩坑也恰好踩在这里。

搬瓦工主打 **CN2 GIA（Global Internet Access）** 线路。CN2 GIA 是中国电信的高端骨干网，全程走专属路由，无论白天还是晚上8点，延迟和丢包都保持在低水平。根据多个社区的实测，搬瓦工洛杉矶 DC6 CN2 GIA-E 机房在国内电信延迟通常在 150ms 左右，晚高峰基本不掉速。

RackNerd 走的是普通 BGP 直连线路。白天体验不差，但晚高峰时段受国际带宽拥堵影响，速度下滑明显、延迟可能翻倍。从实际用户反馈来看，洛杉矶和圣何塞机房相对好一些，但跟 CN2 GIA 比仍有明显差距。

这个差距对不同用户的影响是完全不同的：

- **对建站用户来说**：如果网站受众主要是国内用户，RackNerd 的晚高峰波动会直接影响用户体验和搜索排名。
- **对学习/开发者来说**：主要是白天连 SSH 操作，偶尔高峰期能接受，RackNerd 完全够用。
- **对追求稳定代理/翻墙线路的用户来说**：晚高峰正是用量最大的时候，CN2 GIA 的全天稳定性价值就体现出来了。

## 配置对比：RackNerd 的硬件确实更香

不得不承认，同价位下 RackNerd 的硬件配置比搬瓦工给力得多。

搬瓦工 $49.99/年的入门 KVM 套餐是 1GB 内存、20GB SSD、1TB 月流量。而 RackNerd 同价位（甚至更低）能给到 1.5GB-2GB 内存、30-40GB SSD、2TB 月流量。从账面数字看，RackNerd 赢得清清楚楚。

但这里有个容易忽略的细节：**RackNerd 的流量是双向计算**（进出总量），而搬瓦工很多套餐只计算出向流量。所以账面上 RackNerd 的 2TB 实际等效于搬瓦工的约 1TB。

一位长期使用两家产品的用户在笔记中写道："配合 Hysteria2，RackNerd 要上天了——但只是爬个梯子还是推荐 RackNerd，毕竟便宜；如果建站，还是推荐搬瓦工，安全第一。"这个评价比较客观。
